# Layout families

Four **independent** visual systems — not skins of one template.

| ID              | Used on                | Feel                                                                      |
| --------------- | ---------------------- | ------------------------------------------------------------------------- |
| **A Editorial** | `human-in-the-loop.uk` | Dark, oversized type, full-bleed scenes, scroll theatre of a live handoff |
| **B Flagship**  | `ui121.com`            | Light/precision, product frames, company + product, cinematic             |
| **C Protocol**  | `askmeapi.com`         | Request/response stage, monospace accents, API-as-theatre                 |
| **D Morph**     | `generatedui.app`      | UI that reassembles; JSON-to-surface motion                               |

Remaining domains start from the nearest family and diverge. **No shared Header/Footer components across sites.**
