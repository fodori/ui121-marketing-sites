8. **https://developer.doorDash.com** — [unverified-but-known] DoorDash uses server-driven UI in its consumer apps; a leading native-SDUI case study.

## Embedded UI as a service (precedent)
20. **https://stripe.com/payments/elements** — Verified. Stripe Elements: rich UI building blocks for payments served/hosted by Stripe — the strongest proof that complex UI can be delivered as a managed service.
21. **https://clerk.com** — Verified. Authentication and user management with drop-in UI components ($50m Series C) — managed-UI business model proven.
22. **https://auth0.com** — [unverified-but-known] Universal Login/embedded auth UI as a service — original precedent for outsourced interface surfaces.
23. **https://www.twilio.com** — Verified live. Communications APIs with prebuilt UI surfaces (e.g., Twilio products embedding ready-made UI) — service-embedded-UI adjacency.
24. **https://www.shopify.com/plus/headless** — [unverified-but-known] Shopify headless/Hydrogen: storefront UI decoupled from platform — headless commerce's take on UI delivery.
