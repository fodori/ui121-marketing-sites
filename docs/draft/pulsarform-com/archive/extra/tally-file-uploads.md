# Tally file uploads

Source: https://tally.so/help/file-uploads
Fetched: 2026-09-23
Status: ok
Parent collection: https://tally.so/help/compare

## Summary

Tally lets any form collect images, PDFs, video, audio, and other documents without asking the respondent to create an account. That no-login point is aimed at Google Forms, where an upload can force a Google sign-in. Uploads are free. The free plan caps each file at 10MB. Pro at $29 removes that per-file cap. Authors insert a file block, allow drag-and-drop, optionally require several files with a minimum and maximum count, and can restrict types. The page ties the feature to Tally’s European GDPR posture but does not spell out retention on this URL. Multiple files and size rules are the whole mechanism. There is no review inbox described for the files themselves.

## Key facts

- Free uploads. 10MB per file on the free plan.
- $29 Pro removes the per-file cap.
- No respondent account, unlike some Google Forms uploads.
- Multiple files with min and max counts.
- Types include images, PDFs, video, and audio.

## How it works

The respondent drops a file into the block. Tally stores it with the submission. The operator downloads it later from the response. Nothing in the help page notifies a reviewer inside a thread or lets the respondent replace a file after a human asks.

## Implications for pulsarform.com / ui121

File collection is table stakes. The inbox version is a request for the missing document that stays on the same submission, which Consultations and Aura both gesture at and this help page does not. A 10MB free cap is the market’s default expectation to mention only if Pulsarform’s limit differs.
