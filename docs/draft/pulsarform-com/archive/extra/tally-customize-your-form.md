# Customizing a Tally form

Source: https://tally.so/help/customize-your-form
Fetched: 2026-09-23
Status: ok
Parent collection: https://tally.so/help/compare

## Summary

Tally’s style guide covers light and dark themes, or a custom theme for background, text, button, and accent colors, plus a font. Colors can be picked or typed as hex. A theme has to be saved as a reusable style before it can be applied to another form. Themes cannot be saved on their own yet. Logo, text formatting, and link-preview metadata (image, title, description) are part of the same branding job. Custom CSS is the escape hatch for full control and is not free. An AI shortcut accepts a website URL, a screenshot, or a logo and proposes colors and fonts. The page assumes no coding for the basic theme.

## Key facts

- Light, dark, or custom theme. Hex colors.
- Reuse requires saving a style. Standalone theme library is incomplete.
- Link previews are editable.
- Custom CSS is the advanced, paid path.
- AI can match a site, screenshot, or logo.

## How it works

Open customize, set colors and type, optionally ask the AI to copy a brand, publish. Respondents see a themed form. The submission path does not change.

## Implications for pulsarform.com / ui121

Brand match is how Typeform and Tally win trust in the first screen. Pulsarform should assume themed forms, including an AI pass from a URL, and spend its difference on what happens after the themed submit. Link-preview control matters if a form is shared like a message.
