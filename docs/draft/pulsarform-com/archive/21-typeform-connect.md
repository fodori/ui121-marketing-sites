Fetched: 2026-09-23

## Summary

Typeform Connect is a directory of apps that receive or enrich form activity. Categories in the navigation: analytics and reporting, automation, CMS, collaboration, customer support, developer tools, documents, email marketing, file management, lead generation, marketing automation, payments and e-commerce, productivity, research and customer experience, rewards, sales, and scheduling.

“Most popular” in the extract: Klaviyo (segment and send using real-time data), Calendly (schedule inside the flow), and HubSpot (attract, convert, close). Recommended set: Excel Online, Google Analytics, a Google Forms importer, Intercom, Mailchimp, Microsoft Teams, monday.com (turn responses into leads, orders, and tasks), Notion, and Slack (notify the right people). A further growth set: ActiveCampaign, Facebook pixel, Google Tag Manager, Keap (flagged for a relaunch that the page still dates to Q4 2024, so that notice may be stale), Pipedrive, Salesforce, and Salesforce Classic.

The Salesforce line is the real-time claim: sync Typeform data to Salesforce in real time and automate record creation or updates. Slack is a notification, not a shared case. monday.com is the task object. The page invites app partners to list, and points builders at the Typeform API.

There is no inbox, no respondent reply, and no description of partial submissions. Real time means the CRM or the marketing tool updates when the form completes.

## Key facts

- Directory page, grouped by job (sales, support, payments, research, scheduling).
- Real-time wording attached to Klaviyo data and to Salesforce record sync.
- In-flow scheduling via Calendly. Tasks via monday.com. Alerts via Slack and Teams.
- Google Forms can be turned into a typeform.
- Partner listing and a public API are the extension paths.
- Keap relaunch note on the page still says Q4 2024.

## How it works

A form is connected to an app. On response, Typeform pushes or syncs fields so the other system can mail, score, file a task, or upsert a CRM record. The operator works in that other system. The form remains the collection surface.

## Implications for pulsarform.com / ui121

Incumbent “real time” is integration sync. Pulsarform should offer the same outward sync as a feature and refuse to let it be the headline. The Salesforce sentence is what buyers think real time means. The landing page can say: sync the CRM, and also keep a live thread so the next question does not wait for a sales rep to open Salesforce.

A docs outline for a future integrations page can copy the category list (sales, support, payments, scheduling) and add one category they do not have: the inbox itself.
