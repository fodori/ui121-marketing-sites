# SOURCES.md — ui1to1.com / ui121 research (one-to-one UI, single interface, unified comms)

All URLs verified live during research (Sept 2026). Notes are grounded in page content seen directly or in search-result extracts from the source itself.

## One-to-one / personalized UI

1. **NN/g — Generative UI and Outcome-Oriented Design** — https://www.nngroup.com/articles/generative-ui/ — Verified via full extract. "GenUI promises highly personalized interfaces — a move from designing for many to tailoring for the individual." Core citation for the problem with one-to-many UIs.

2. **Google Research — Generative UI: a rich, custom, visual interactive user experience for any prompt** (Nov 2025) — https://research.google/blog/generative-ui-a-rich-custom-visual-interactive-user-experience-for-any-prompt/ — Verified via extract. Models output HTML/CSS/JS on the fly, rolling out in Gemini and Search AI Mode; proof that server/AI-authored UI is now mainstream.

3. **UX Design (Taras Bakusevych) — Hyper-personalization: a practical UX guide** (Feb 2025) — https://uxdesign.cc/hyper-personalization-a-practical-guide-8e5f7b89e26e — Dynamic UI personalization: interfaces adapt layout, content, visuals per user; explicit + implicit feedback loops.

4. **Readability Matters — Generative UI Meets Better Readability** (Jul 2025) — https://readabilitymatters.org/articles/generative-ui-meets-better-readability — Frames the shift: "Today: same interface for everyone → Future with GenUI: personalized interface for each user; unique interfaces for every end-user's session."

5. **Pagent — How generative AI enables hyper-personalization in UI/UX design** (Oct 2024) — https://www.pagent.ai/blog/hyper-personalization-ui-ux-design/ — "In a world where the UI is adaptive to the user's intention, interfaces could…". Hyper-personalized experience per unique user.

6. **AvidClan — The Rise of Personalization in UX/UI: designing unique experiences for every user** (May 2025) — https://www.avidclan.com/blog/the-rise-of-personalization-in-ux-ui-how-to-design-unique-experiences-for-every-user/ — Beyond name-stamping personalization: designing experiences that are intuitive and relevant per user.

7. **Reddit r/UXDesign — What if AI could generate unique UI for every user, in real-time?** (Nov 2023) — https://www.reddit.com/r/UXDesign/comments/180d9wj/what_if_ai_could_generate_unique_ui_for_every/ — Community discussion of the exact thesis ui121 productizes; shows early demand-side thinking.

8. **Google Cloud — What is Generative UI? Building Agent-Powered Interfaces** — https://cloud.google.com/discover/generative-ui — UI as a flexible orchestration layer; can instantly reconfigure a dashboard or generate a functional mini-app.

## Tool sprawl / single interface

9. **RescueTime — Tool debt: how using too many productivity tools hurts productivity** — https://blog.rescuetime.com/tool-debt/ — Verified via extract. Workers use 4× the tools of the early 2000s; 96% dissatisfied with workplace tools; a single article task touches six tools.

10. **Speakwise — Workplace Technology Overload Statistics 2026** — https://speakwiseapp.com/blog/workplace-technology-overload-statistics — Workers toggle between apps ~1,200×/day; average company deploys ~101 SaaS apps; ~44 hours/year lost.

11. **Speakwise — Workplace Productivity Tools Statistics 2026** — https://speakwiseapp.com/blog/workplace-productivity-tools-statistics — ~106 SaaS apps per company; up to 40% of productive time lost to context switching.

12. **MindStudio — What is the Three-Tool Rule?** (Mar 2026) — https://www.mindstudio.ai/blog/three-tool-rule-ai-productivity — Cites Gloria Mark's research: ~23 minutes to refocus after a switch; knowledge workers switch tasks/apps frequently.

13. **Access Group — App overload: the power of a single system** — https://www.theaccessgroup.com/en-gb/blog/nfp-app-overload-power-of-a-single-volunteer-management-system/ — App overload as the dominant form of context switching; consolidation benefit case study (UK source, good for ui121's UK story).

14. **Medium (Design Bootcamp) — The Fatigue of Being Online: cognitive overload as the new burnout** (Nov 2025) — https://medium.com/design-bootcamp/the-fatigue-of-being-online-why-cognitive-overload-is-the-new-burnout-0d10434d113a — Digital burnout from managing too many surfaces; human cost of fragmented UIs.

## Real-time / collaborative UI tech

21. **Yjs — homepage & docs** — https://yjs.dev — Verified via extract. CRDT-based shared types that "sync automatically," offline support, network-agnostic. The state of the art for real-time collaborative state, which a universal live canvas must match.

22. **rjsf-team/react-jsonschema-form (GitHub, ~15.9k★)** — https://github.com/rjsf-team/react-jsonschema-form — Verified via extract. The mainstream proof of JSON/data-described forms; JSONUI generalizes this from forms to full canvases.

23. **Vercel AI SDK — Generative User Interfaces** — https://ai-sdk.dev/docs/ai-sdk-ui/generative-user-interfaces — Model + tools decide which UI to render from conversation/context; streaming server-driven UI pattern ui121's JSONUI is aligned with. Related: https://ai-sdk.dev/docs/ai-sdk-rsc/generative-ui-state

24. **Monterail — Revolutionizing chatbot interactions with Generative UI** (Aug 2026) — https://www.monterail.com/blog/revolutionizing-chatbot-interactions-with-generative-ui — Practical account of Vercel's streamUI/React Server Components: UI components stream from server to client.

25. **Gel — Generative UI with Vercel AI SDK and EdgeDB** (Mar 2024) — https://www.geldata.com/blog/generative-ui-with-vercel-ai-sdk-and-edgedb — Early practitioner write-up of customized interactive UI generated by AI.

## Human-in-the-loop automation

26. **IBM — What is Human in the Loop (HITL)?** — https://www.ibm.com/think/topics/human-in-the-loop — Verified via extract. Automation efficiency without sacrificing human precision/nuance/ethics.

27. **Workflowbuilder — What is human-in-the-loop automation? A practical guide** (Sep 2026) — https://www.workflowbuilder.io/blog/human-in-the-loop-automation — Key distinction ui121's pitch rides on: "a workflow that emails someone a notification" is NOT HITL; real HITL means the human acts inside the process.

28. **Microsoft Learn — Agent Framework Workflows: Human-in-the-loop (HITL)** — https://learn.microsoft.com/en-us/agent-framework/workflows/human-in-the-loop — Formalization of human checkpoints (RequestPort pattern) in mainstream agent orchestration.

29. **Tines — Human-in-the-loop workflows: where intelligent automation meets judgment** (Jun 2026) — https://www.tines.com/blog/human-in-the-loop-workflows-where-intelligent-automation-meets-judgment/ — When and where to insert human checkpoints; avoiding bottlenecks.

30. **Camunda — What is human in the loop automation** (Jun 2024) — https://camunda.com/blog/2024/06/what-is-human-in-the-loop-automation/ — Process platforms orchestrate interaction between automated and human tasks.

31. **AWS ML Blog — Implement human-in-the-loop confirmation with Amazon Bedrock agents** (Apr 2025) — https://aws.amazon.com/blogs/machine-learning/implement-human-in-the-loop-confirmation-with-amazon-bedrock-agents/ — Human oversight/confirmation in agent runs.

32. **Oracle — Human in the Loop for Agentic AI in Oracle Integration** — https://docs.oracle.com/en/cloud/paas/application-integration/human-loop/human-loop-agentic-ai-oracle-integration.html — Human approval, feedback, oversight in agentic automation; creation of approval workflows and forms.

## Agent↔tool / internal-tools landscape

33. **Model Context Protocol — What is MCP?** — https://modelcontextprotocol.io — Verified via extract. "USB-C port for AI applications"; includes "MCP Apps": interactive apps that run inside AI clients — the agent side that ui121's human canvas complements.

34. **Orkes — Human-in-the-Loop in agentic workflows** (Aug 2025) — https://orkes.io/blog/human-in-the-loop — Hybrid model: automation speed for routine steps, humans for judgment.

35. **Retool — Build internal software better, with AI** — https://retool.com — Verified via extract. The incumbent category (AI-built internal tools, MCP-based building, agent governance) ui121's universal canvas competes against and beyond.
